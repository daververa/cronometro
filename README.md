# Cronómetro Pomodoro (Expo)

App mínima de prueba: 25 min de enfoque / 5 min de descanso, con iniciar, pausar, reiniciar y contador de pomodoros.

## Probarla en Windows

```bash
cd Desktop\cronometro
npm install
npx expo start
```

- Presiona **w** para verla en el navegador.
- O instala **Expo Go** en el iPad y escanea el código QR (misma red Wi-Fi).

El código principal está en `App.js`.
